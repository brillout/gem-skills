About

Gem Skills lists 163 of the most popular agent skills, ranked by real usage and tagged by what they do, need and change.

How popularity is measured

  • Installs are all-time installs on skills.sh, Vercel's registry for the npx skills CLI, from its top 600 on Sep 21, 2026. They also give the weekly trend.
  • Downloads come from ClawHub, the OpenClaw registry, and Tencent SkillHub, on Sep 21, 2026. They aren't comparable with skills.sh installs.
  • Stars belong to the GitHub repo behind a skill, collected on Sep 21, 2026.

Read the numbers with care

  • Skills of one repo share counts. skills.sh counts an install of a repo once per skill in it, so skills from one repo sit close together. Turn on One per repo to see one entry per repo.
  • Some skills are copies. 12 skills here are republished copies of another publisher's skill, with install counts far above their originals'. They carry flag:republished.
  • Some skills are left out. The list skips 117 skills; Show all brings them back, and their pages stay.
    • flag:deprecated Retired: its SKILL.md points to a replacement, which is the skill to discover.
    • flag:tool-docs A skill that's an agent's manual for a product (how to build with it, configure it, deploy to it or operate it) only matters once you've already chosen that product, so nobody discovers anything by browsing it. That said, a skill that gives a new capability through some tool does get listed — that's what GemSkills is for.
    • lang:zh Not in English, so most visitors can't read it.
    • Skills gone from their source can no longer be installed.
  • CI installs count too, so skills wired into pipelines are over-represented.

Bundles

Some repos ship skills meant to be used together, such as the steps of a workflow: Superpowers, Caveman, Writing workflow, Engineering workflow, RigorPilot, BrowserAct. A bundle gets one entry, with its skills inside in the order they're used. A skill that also works alone keeps its own entry, with a link to its bundle; one that needs the rest of the bundle is only listed inside it. A bundle's installs are those of its most installed skill.

Tags

Each skill has one or more categories, one type, one effect and one publisher, plus what it needs, its stack, one to five topics and any flags. The Tags page explains every value. Tags were assigned from each skill's SKILL.md on Oct 19, 2026. Eleven ClawHub and Tencent SkillHub skills were tagged from their registry description because their SKILL.md couldn't be read. by:official is conservative: unverified vendor claims count as community.

Data

Everything on this site comes from one file, skills.json. To add or correct a skill, edit it and open a pull request.

Each skill's page shows a copy of its SKILL.md, from data/skill-snapshots/. A daily job checks every SKILL.md at its source, except the skipped skills', and updates the copy when it changes.

Sources: skills.sh (installs, weekly trend), ClawHub and Tencent SkillHub (downloads), GitHub (stars), and AWS's June 2026 survey for two repos that aren't packaged as skills.
